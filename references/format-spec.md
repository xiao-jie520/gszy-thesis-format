# 撰写规范条文与细则

来源：《甘肃中医药大学 医学信息工程学院本科毕业论文（设计）撰写规范建议及示例》及其附件 2
《本科毕业论文（设计）格式排版注意事项》。以下为可直接执行的条文，括号内注明原文出处。

## 一、版面

| 项目 | 要求 |
| --- | --- |
| 纸张 | A4（210×297 mm）标准白纸，左侧装订成册 |
| 页边距 | 上 35 mm、下 25 mm、左 25 mm、右 25 mm |
| 页眉 | 内容「甘肃中医药大学本科毕业论文（设计）」，宋体五号居中，页眉距边界 25 mm |
| 页脚 | 页码宋体小五，底端居中，页脚距边界 20 mm |
| 行距 | 1.5 倍行距 |

## 二、字体字号

| 部位 | 要求 |
| --- | --- |
| 封面「××学院毕业论文（设计）」 | 楷体小二号加粗（照抄原模板） |
| 封面论文标题 | 黑体二号加粗，题目不超过 30 字，可排两行 |
| 一级标题（章） | 黑体小三号，居中，1.5 倍行距，段前段后各 1 行，每章另起一页 |
| 二、三级标题 | 黑体小四号，左对齐，1.5 倍行距，段前段后各 6 磅 |
| 正文 | 宋体小四号；英文与数字 Times New Roman |
| 摘要标题「摘　　要」 | 黑体小三，居中，1.5 倍行距，段前段后 1 行 |
| 「【关键词】」 | 黑体小四，其后关键词宋体小四 |
| Abstract 标题 | Times New Roman 小三加粗，居中，1.5 倍行距，段前段后 1 行 |
| 「【Keywords】」 | 加粗，其后关键词 Times New Roman 小四 |
| 目录标题「目　　录」 | 黑体小三 |
| 目录条目与页码 | 宋体小四 |
| 图题、表题 | 宋体五号，居中 |
| 表格内文字 | 宋体五号；英文数字 Times New Roman 五号 |
| 参考文献 | 宋体五号；英文 Times New Roman 五号，居左 |
| 页码 | 宋体小五 |

> 正文字号与行距的完整表述：每段落首行缩进 2 字符，宋体小四，多倍行距 1.5，段前段后 0，**取消"对齐到网格"**。

## 三、装订顺序

（1）封面；（2）题目内页；（3）版权使用授权书；（4）中文摘要、关键词；（5）英文摘要、关键词；
（6）目录；（7）正文；（8）总结；（9）致谢；（10）参考文献；（11）附录。

正文之后按示例先后为：总结 → 致谢 → 参考文献 → 附录。论文封面用 150 g 皮纹纸白色印制。

## 四、摘要与关键词

- 摘要含研究目的、方法、成果、结论，不含图表、不加注释，300～500 字（示例处又要求"不少于 500 字"，取 500 字以上更稳妥）
- 英文摘要与中文摘要内容完全一致，不用机器翻译，用第三人称、现在时、被动语态
- 「摘要」标题与正文之间不空行；关键词与摘要正文之间**空一行**
- 中文关键词 3～5 个，分号分隔，末尾不加标点，宋体小四
- 「【关键词】」三字加粗（黑体小四），不可省略
- 英文关键词与中文一一对应，词间**两个空格**，末尾不加标点，每个词所有实词首字母大写，换行后不缩进
- 摘要与结论中的编号用 (1)、(2) 形式，编号字体 Times New Roman

## 五、标题层级

| 层次 | 示例 | 说明 |
| --- | --- | --- |
| 章 | `第1章　引言` | 章序用阿拉伯数字，章序与章名居中排 |
| 节 | `1.1　引言背景` | 顶格书写，题序与标题间空一格，小四黑体，段前段后 6 磅 |
| 条 | `1.1.1　三级标题` | 同上 |

- 最多三级标题，**不得出现四级标题**
- 正文中的文字编号最多两级：一级用（1）（2），二级用①②；字号与正文一致，首行缩进 2 字符，无悬挂缩进，**手动编号**，不用自动编号列表
- 各章之间用分页符分隔

> 原模板正文示例里还残留 `1　引言` 的写法，但「表1 层次代号及说明」与目录示例统一为 `第1章 引言`。本技能采用 `第1章` 写法，脚本会把 `# 1 引言` 自动改写为 `第1章 引言`。

## 六、图

- 图居中排列，与上文留一行空白；图题置于图下居中，宋体五号，图题与图之间不留空行
- 分章编号：图3-1、图3-2；分图用 a)、b)、c)，分图题置于分图下，不能省略
- 图与图题为一个整体，不得跨页；本页排不下时整图移到次页最前面
- 版式为「嵌入型」或「上下型」，不得浮于文字之上
- 图中文字不得大于正文字号，全文一致；变量用斜体，第一次出现须在正文说明
- 插图前正文必须有提示，如"如图3-1所示"，不得用"上图""下图"
- 各类图宽度不超过版心宽度的 2/3（约 10.7 cm）；程序截图不受此限但须清晰
- E-R 图、系统框架图、数据流图用 Visio 等绘制，导出图片 dpi 不低于 300；图中字号比正文小一号（正文小四 → 图中五号）

## 七、表

- 尽可能用三线表：上下边线 1.5 磅，表头下边线 0.5 磅，无竖线、无其他横线
- 不能用三线表表达的，建议改为图
- 表题在表上方居中，宋体五号，与表之间不留空行；表格居中，与下文留一行空白
- 分章编号：表3-1；跨页续表写「续表3-1」，左对齐或顶格
- 各栏标注量与单位；数字上下对齐；相邻栏数值相同也要逐格重写，不得写"同上""同左"
- 表内汉字统一宋体五号，英文数字 Times New Roman 五号
- 表名可被引用，正文中必须引用，如"见表2-1"

## 八、公式

- 行间公式居中，编号右对齐、加圆括号，分章编号：式(3-1)、式(3-2)，公式与编号之间不加虚线
- 公式与上下文之间段前段后 6 磅（或 0.5 行）
- 公式字号不大于正文；公式说明另起段落，不缩进
- 变量与一般函数用斜体；矢量、矩阵用粗斜体；有定义的已知函数（sin、exp、ln）、数学常数、单位、化学元素、型号等用正体；描述性下标用正体
- 插入方式：MathType 右编号公式，或用 1 行 2 列无框表格"公式 + 编号"（本技能采用后者）

## 九、参考文献

- 按正文引用顺序编号，正文中以上标方括号标注，如 `******[1]`；标题中不能出现引用
- 作者姓前名后，外文名缩写；作者间用英文半角逗号；少于 3 人全部列出，3 人以上列前 3 人后加"等"或"et al"
- 标点一律用英文标点，标点后加一个空格
- 各类型著录格式：

```
专著      [序号] 作者.书名(版本)[M].出版地:出版者,出版年:起止页码.
期刊      [序号] 作者.题名[J].刊名,出版年,卷(期):起止页码.
会议论文  [序号] 作者.题名[A].见(In):编者.论文集名[C].出版地:出版者,出版年:起止页码.
电子文献  [序号] 作者.题名[电子文献载体类型].出版地:出版者,发表或更新日期:起止页码.
学位论文  [序号] 作者.题名[D].保存地点:保存单位,年份:起止页码.
专利      [序号] 专利申请者.题名[P].专利国别,专利文献种类,专利号,出版(授权或公布)日期.
标准      [序号] 技术标准(责任者,编者),标准编号 标准名称[S].出版地:出版者,出版年:起止页码.
```

- 期刊若无卷可不写；上述 7 类以外的文献不得列入参考文献，可写入致谢

## 十、其他要求

- 汉字用规范简化字；数字用法遵循 GB/T 15835；量和单位遵循 GB 3100～3102；标点遵循 GB/T 15834
- 公历纪年、时间、计数计量用阿拉伯数字，Times New Roman；年份不简写（1999 年不能写成 99 年）；有效数字写全（0.50:2.00 不能写成 0.5:2）
- 括号使用：括号内全为英文用半角，否则用全角，如 `(support vector machine, SVM)`、`（支持向量机，SVM）`
- 英文专有名词大小写全文统一（如 Spring Boot 不要一会儿全大写一会儿全小写）
- 正文不出现多余空格、空回车；文字之间不留空行；文字与图之间不留多行空白
- 正文不放整段代码，代码放附录；附录中代码可用高亮工具格式化
- 附录图、表另行编号：附图1、附表2，或图A1、表B2；附录内容分部分编写：附录1 ×××、附录2 ×××
- 打印：前置部分（中英文摘要、目录）单面打印，正文到致谢双面打印

## 十一、最常被判不合格的十六条

1. 页边距不是「上 3.5 / 下 2.5 / 左右 2.5」
2. 页眉漏掉或写成「甘肃中医药大学毕业论文（设计）」（少了"本科"）
3. 摘要与正文页码没有分段：全文用同一套阿拉伯数字
4. 正文没有首行缩进 2 字符，或用空格顶出缩进
5. 中文字体混用宋体/仿宋/微软雅黑；英文与数字没改成 Times New Roman
6. 行距不是 1.5 倍，或没有取消"对齐到网格"导致行距忽大忽小
7. 一级标题没有另起一页，或没有居中
8. 出现四级标题，或标题用了自动编号（1、1.1 之外多出 1.1.1.1）
9. 图题写图上方、表题写表下方（正好相反）
10. 图表编号用连续编号与分章编号混用，或编号跳号
11. 表格不是三线表，或三线表带竖线
12. 公式编号没有右对齐，或没有加圆括号
13. 正文用"上图""下表"指代图表，没有写编号
14. 关键词不足 3 个或超过 5 个，或用逗号分隔
15. 参考文献序号与正文引用顺序不一致，标点用中文标点
16. 目录是手工敲的，页码与正文对不上（应用目录域自动生成）
